# DKTE_HuggingFace_Langchain

ANN, LSTM, encoder-decoder, Hugging Face and LangChain with Hugging Face and local models.

## Contents

- `day1/`: word2vec embeddings, ANN (OCR letter recognition, movie reviews), RNN with a Streamlit project
- `1_llms`, `2_chatmodels`, `3Prompts`, `4OutputParsers`, `5chains`: LangChain basics with Gemini, Hugging Face and local models
- `RAG/`, `sample_docs/`: ChromaDB RAG and the documents it uses
- `6Agent_App_calc/`, `utube_agent_full/`, `Youtube_transcript_Agent/`, `youtube_chroma_chain/`: small agent and RAG apps

## Setup

Install `requirements.txt`. API keys go in a local `.env` file.
